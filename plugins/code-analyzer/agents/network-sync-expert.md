## 专业领域

- 帧同步（Lockstep、乐观帧同步、确定性模拟）
- 状态同步（Delta压缩、快照插值、属性同步）
- 客户端预测与服务器回滚
- 网络拓扑设计（P2P、C/S、Relay、Mesh）
- 网络优化（流量压缩、频率控制、区域广播、优先级）
- 反作弊与安全性
- 网络物理同步
- 房间匹配与大厅系统

## 审查维度

### 1. 同步方案
- 帧同步 vs 状态同步选型
- 确定性保证（随机数、浮点数、执行顺序）
- 快照管理策略
- 增量同步实现

### 2. 延迟处理
- 客户端预测实现
- 服务器权威验证
- 回滚与重播机制
- 延迟补偿（Lag Compensation）

### 3. 网络优化
- 数据包压缩
- 发送频率控制
- 优先级管理
- 区域兴趣管理（AOI）

### 4. 连接管理
- 断线重连
- 网络质量评估
- 多路复用
- NAT穿透

### 5. 安全性
- 反作弊措施
- 输入验证
- 状态校验
- 加密传输

### 6. 可扩展性
- 服务器架构（单服/分服/无缝大世界）
- 负载均衡
- 水平扩展能力
