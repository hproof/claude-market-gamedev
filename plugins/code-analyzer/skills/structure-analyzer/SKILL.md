  代码结构分析 Skill。负责分析代码的目录结构、类关系、模块依赖等。
  当用户选择"结构分析"类型时触发。
  适用于：代码组织评估、架构重构前分析、依赖关系梳理。

执行代码结构分析，识别目录组织、类/接口关系、模块依赖。

**定位：深度结构分析。** 深入到文件级的 include/import 关系，分析类的继承/组合关系、循环依赖、耦合度等。
与 `full-scan` 的区别：`full-scan` 只做宏观概览（识别模块边界和层级），本 Skill 深入模块内部做详细分析。

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `scope` | string | 否 | 分析范围（目录路径），默认为当前目录 `.` |
| `output_file` | string | 否 | 输出文件路径，由调用方指定 |

## 工作流程

1. **目录结构分析**
   - 扫描目录层级
   - 识别代码文件分布
   - 分析命名规范和目录组织

2. **类/接口关系分析**
   - 识别主要类和接口
   - 分析继承关系
   - 分析组合/聚合关系

3. **模块依赖分析**
   - 分析文件间的 include/import 关系
   - 识别循环依赖
   - 评估模块内聚性和耦合度

4. **生成分析报告**
   - 输出到指定的 `output_file`

## 容错处理

| 情况 | 处理方式 |
|------|----------|
| 目标路径不存在 | 终止分析，返回错误信息 |
| 目录为空或无代码文件 | 生成空报告，标注"无代码文件" |
| `.claudeignore` 不存在 | 正常执行，不忽略任何文件 |

## 输出规范

**输出文件**：由调用方通过 `output_file` 参数指定

示例：`./docs/code-analyzer/src-structure.md`
