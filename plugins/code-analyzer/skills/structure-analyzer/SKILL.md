执行代码结构分析，识别目录组织、类/接口关系、模块依赖。

**定位：深度结构分析。** 深入到文件级的 include/import 关系，分析类的继承/组合关系、循环依赖、耦合度等。
与 `full-scan` 的区别：`full-scan` 只做宏观概览（识别模块边界和层级），本 Skill 深入模块内部做详细分析。

## 工作流程

1. **目录结构分析**
   - 扫描目录层级（遵循 `.claudeignore` 忽略规则）
   - 识别代码文件分布
   - 分析命名规范和目录组织

2. **类/接口关系分析**
   - 识别主要类和接口
   - 分析继承关系
   - 分析组合/聚合关系

3. **模块依赖分析**
   - 分析文件间的 include/import 关系
   - 识别循环依赖
   - 评估模块内聚性和耦合度

4. **生成分析报告**
   - 输出到指定的 `output_file`

## 额外评分维度

结构分析在通用维度基础上，额外评估：

| 维度 | 评估要点 |
|------|----------|
| **目录组织** | 层级深度、职责分离、命名规范 |
| **类设计** | 单一职责、继承合理、接口清晰 |
| **依赖管理** | 无循环依赖、依赖方向正确 |
