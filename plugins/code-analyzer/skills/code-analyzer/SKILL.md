分析游戏项目代码架构与实现，自动生成审查文档。

## 工作流程

1. **提取参数** - 从用户提示中提取：
   - 目标代码路径
   - 分析需求描述（用于目录命名）

2. **调用负责人** - 使用 `analysis-leader` agent 执行分析：
   - 传递目标路径、分析描述
   - 负责人自动识别领域、调度专家、生成汇总

## 输出结构

```
./docs/
└── {日期}-{分析需求提要}/
    ├── summary.md          # 总概括文档（含综合评分）
    ├── architecture.md     # 各领域专家生成
    ├── rendering.md
    ├── network.md
    └── ...
```

**目录命名**：`{日期}-{分析需求提要}`
- 示例：`2026-03-19-渲染模块审查/`

## 评分说明

- 各专家从5个维度评分（1-10分）
- 生成领域综合评分和项目总体评分
- 支持评分雷达图数据

详细评分规则见 reference.md
