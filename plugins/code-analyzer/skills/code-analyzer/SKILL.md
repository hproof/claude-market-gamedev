分析游戏项目代码架构与实现，自动生成审查文档。

## 工作流程

1. **提取参数** - 从用户提示中提取：
   - 目标代码路径
   - 分析需求描述（用于目录命名）

2. **调用负责人** - 使用 `analysis-leader` agent 执行分析：
   - 传递目标路径、分析描述
   - 负责人自动识别领域、调度专家、生成汇总

## 输出结构

```
./docs/
└── {日期}-{时间}-{分析需求提要}/
    ├── summary.md          # 总概括文档（含综合评分）
    ├── code-structure.md   # 代码结构分析（始终生成）
    ├── code-quality.md     # 代码质量分析（始终生成）
    ├── game-flow.md        # 游戏流程分析
    ├── object.md           # 对象管理分析
    ├── scene.md            # 场景管理分析
    ├── rendering.md        # 渲染管线分析
    ├── network.md          # 网络流程分析
    ├── physics.md          # 物理引擎分析
    └── ui.md               # UI框架分析
```

**目录命名**：`{日期}-{时间}-{分析需求提要}`
- 示例：`2026-03-19-143052-渲染模块审查/`

## 评分说明

- 各专家从5个维度评分（1-10分）
- 生成领域综合评分和项目总体评分
- 支持评分雷达图数据

详细评分规则见 reference.md
