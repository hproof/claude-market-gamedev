执行关键流程分析，识别初始化、主循环、网络同步、业务流程等。

## 工作流程

1. **初始化流程分析**
   - 识别程序入口
   - 追踪初始化调用链
   - 分析模块加载顺序

2. **主循环流程分析**
   - 识别主循环位置
   - 分析每帧执行流程
   - 识别更新顺序

3. **网络同步流程分析**
   - 分析发包流程
   - 分析收包流程
   - 识别状态同步机制

4. **关键业务流程分析**
   - 识别典型业务入口
   - 追踪业务执行流程
   - 分析与底层模块的交互

5. **生成分析报告**
   - 输出到指定的 `output_file`

## 额外评分维度

流程分析在通用维度基础上，额外评估：

| 维度 | 评估要点 |
|------|----------|
| **流程清晰度** | 步骤明确、职责分离、易于追踪 |
| **性能** | 无冗余操作、优化合理、资源管理 |
| **健壮性** | 错误处理、状态恢复、边界处理 |
