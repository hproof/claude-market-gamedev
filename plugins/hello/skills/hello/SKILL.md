向用户问好并显示系统信息。

## 执行步骤

1. 获取当前系统信息：
   - 使用 Bash 工具执行 `date` 命令获取当前日期时间
   - 使用 Bash 工具执行 `whoami` 或 `echo %USERNAME%` 获取当前用户
   - 使用 Bash 工具执行 `uname -a` 或 `ver` 获取操作系统信息
   - 使用 Bash 工具执行 `pwd` 获取当前工作目录

2. 以友好的方式向用户问好，并展示收集到的系统信息

## 输出格式

使用以下格式输出：

```
👋 你好，[用户名]！

📅 当前时间：[日期时间]
💻 操作系统：[系统信息]
📂 工作目录：[当前目录]
🎮 祝你使用愉快！
```
